# PickerHub

مختبر ألوان عربي يعمل محلياً على Windows وLinux وmacOS. افتح **PickerHub.html** في متصفح سطح المكتب. يضم الملف واجهة RTL وخطوطها ومحرك Rust المترجم إلى WebAssembly. لا يتطلب تشغيل النسخة الجاهزة حساباً أو اتصالاً بالإنترنت.

## ابدأ بلون واحد

1. افتح **ملتقط الألوان ← التقاط من الشاشة**. استخدم قطّارة النظام، أو افتح المعاينة واختر الشاشة أو النافذة من نافذة الأذونات. حرّك المؤشر داخل المعاينة، واضبط التكبير ثم اختر البكسل. تعمل الأسهم للتحرك بكسلاً واحداً وEnter للاختيار وEsc للإلغاء.
2. انقر على صف HEX أو RGB أو RGBA أو HSL أو HSV أو HSB أو CMYK لنسخه. ينسخ الزر المجاور لعنوان «صيغ اللون» جميع القيم. من زر القلم يمكنك كتابة قيمة مثل `#87CEEB` وسترى الاسم «أزرق سماوي». يعرض زر المعلومات الدرجة والسطوع ولون العيّنة المرجعية.
3. اضغط **إضافة إلى لوحة** لحفظ اللون. لإنشاء لوحة ثانية انتقل إلى **لوحات الألوان ← لوحة جديدة**. استخدم الأسهم لإعادة ترتيب الألوان، أو اختر **نقل** لاختيار لوحة الوجهة.
4. جرّب **تناغم الألوان ← ثلاثية**. احفظ المجموعة كلها أو افتح عيّنة لحفظها وحدها. توفر القائمة أيضاً الألوان المتجاورة والمتكاملة والمتكاملة المنقسمة وأحادية اللون وعالية التباين.
5. من اللوحة اختر **تصدير ← متغيرات CSS**. يتضمن الملف تصريحاً مثل `--color-1-أزرق-سماوي: #87CEEB;` داخل `:root`. يمكنك أيضاً تصدير SCSS وJSON وCSV وTXT وGPL لاستيراده في GIMP أو Inkscape. يصدّر زر التنزيل تحت عيّنة الملتقط لوناً منفرداً.

## أدوات المختبر

| الأداة | مثال للاستخدام |
| --- | --- |
| فحص التباين | اختر لون النص والخلفية. يعطي الأسود فوق الأبيض ‎21:1‎. تظهر نتائج AA وAAA للنص العادي والكبير، مع اقتراح نص بديل عند إخفاق AA العادي. |
| تحليل الصور | أسقط ملف PNG أو JPEG أو WEBP، ثم افحص الألوان بالترتيب النسبي. اختر **حفظ كلوحة** أو صدّر النتيجة مباشرة. |
| محرّر التدرجات | اختر خطياً أو دائرياً. أضف نقاطاً وحرّك مقابض مواقعها، وغيّر زاوية التدرج الخطي. انسخ CSS أو نزّله، واحفظ التدرج باسم. يمكن إعادة فتح المحفوظ وتحديثه، أو بدء تدرج جديد. |
| سجل الألوان | اختر لوناً سابقاً أو انسخه أو احذفه. غيّر الحد بين 1 و256. تقليص الحد يزيل أقدم العناصر الزائدة. |
| النسخ الاحتياطي | من زر الأرشيف في الشريط العلوي نزّل نسخة JSON. استعدها عند تغيير الجهاز أو المتصفح أو مسار الملف. تعرض الواجهة تأكيداً قبل استبدال المكتبة. |
| المظهر | يبدّل زر الشمس أو القمر بين المظهرين ويحفظ التفضيل مع المكتبة. |

## خصوصية البيانات ودقة القياس

تقرأ المعاينة تدفق الشاشة التي يوافق عليها المستخدم. ينتهي التدفق عند الاختيار أو الإغلاق. لا تُحفظ اللقطات أو الصور في المكتبة. تحظر سياسة المحتوى اتصالات الشبكة، ويتضمن الملف الخطوط والمحرك محلياً. يعتمد التخزين على ملف تعريف المتصفح ومسار التطبيق، وقد يُمسح مع بيانات المتصفح أو عند إغلاق التصفح الخاص.

الألوان بصيغة sRGB معتمة، ومن ثم تكون قيمة ألفا 1. تتطابق HSB وHSV. قيم CMYK حسابية تقريبية، وقد تختلف عن مخرجات الطباعة ذات ملف ICC. تعتمد الأسماء على أقرب عيّنة في قاموس عربي/إنجليزي. يحسب الفاحص نسبة الإضاءة النسبية قبل تقريب العرض. وتعرض أداة الصور أعلى عشر مجموعات من عيّنة لا يتجاوز ضلعها الأطول 768 بكسلاً، مع وزن الشفافية. [معيار التباين لدى W3C](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

## التثبيت والبناء

راجع [كتيب التثبيت لكل نظام](docs/install.md) للنسخ الجاهزة والبناء من المصدر والأذونات وحلول المشكلات.

```sh
rustup target add wasm32-unknown-unknown
cargo test --locked
python3 scripts/build.py --packages
```

يوجد التطبيق والحزم الناتجة في `dist/`. في Windows استخدم `py -3` مكان `python3`.
