# PickerHub

<img src="desktop/Assets/icon-256.png" width="112" alt="أيقونة PickerHub: حرف P أصفر على خلفية سوداء، تجويفه عدسة القطّارة وبداخلها البكسل الملتقط">

مختبر ألوان عربي لسطح المكتب على Windows وLinux وmacOS. يعرض التطبيق نافذته الخاصة ويشغّل محرك Rust محلياً، مع واجهة Avalonia، وخطوط عربية مضمّنة ومكتبة محفوظة على الجهاز.

## إصدار 0.6.1 التجريبي

تتوفر واجهة إنجليزية من الإعدادات مباشرة، إضافة إلى العربية. تدعم النسخة النسخ التلقائي، الاختصارات العامة الاختيارية، التقاط ألوان متتابعة، والتراجع والإعادة. تتضمن المكتبة شبكة وقائمة وبحثاً ومفضلة وإجراءات جماعية، مع أرشيف باقات يومية وتصدير أدوار CSS وDesign Tokens ومصفوفة تباين.

[ما نُفذ وكيف اختُبر وما يلزم قبل النشر](docs/production-readiness.md). الحزم المحلية مرشحة للاختبار؛ توقيع Windows وتوثيق macOS يحتاجان بيانات الناشر.

[تنزيل الإصدار](https://github.com/hussamty/PickerHub/releases) · [تجربة Windows 11](docs/windows-test.md)

تظهر داخل العدسة في الالتقاط المتعدد أعداد الألوان وعينات آخر ستة ألوان. فتح التطبيق مرتين يعيد تنشيط النافذة نفسها. الإصدارات التجريبية غير موقعة بشهادة ناشر، والتحديث التلقائي غير مفعّل.

## التقاط لون

اضغط **القطّارة** أو **F8** من نافذة PickerHub. تختفي النافذة أثناء الاختيار. انقر على اللون لحفظه في السجل ونسخه تلقائياً بالصيغة التي اخترتها أو اضغط **Esc** للعودة إلى التطبيق.

على **Wayland** تستعمل القطّارة عدسة إضافة GNOME Color Picker عندما تكون مفعّلة وتوفّر واجهة D-Bus، وإلا تستدعي منتقي ألوان النظام. يتلقى PickerHub قيمة اللون المختار فقط. للتنقل بـ**Alt+Tab** أثناء الاختيار ومتابعة المحتوى المتحرك، فعّل **استخدام عدسة PickerHub عبر مشاركة الشاشة** من الإعدادات. في هذا الوضع يطلب النظام تحديد الشاشات وتظل المشاركة قائمة حتى تنهيها أو تغلق التطبيق.

على **Windows وX11** تدعم عدسة PickerHub تبديل النوافذ، والتكبير بعجلة الفأرة، وتحريك نقطة الاختيار بالأسهم. على **macOS** يتولى النظام عرض القطّارة.

## أدوات المختبر

- اضغط صيغة لنسخ HEX أو RGB أو RGBA أو HSL أو HSV أو HSB أو CMYK. يعرض الملتقط الاسم العربي والإنجليزي والدرجة والسطوع وأقرب عينة. يعيّن تعديل HEX اللون مباشرة، مثل ‎#87CEEB‎ للأزرق السماوي.
- احفظ اللون في لوحة أو اختر تناغماً واحفظ المجموعة. تنشئ صفحة اللوحات مكتبات مسمّاة وتتيح تعديل الأسماء والترتيب والنقل والحذف. من «تصدير اللوحة» اختر CSS أو SCSS أو JSON أو CSV أو TXT أو GPL لـGIMP وInkscape.
- اختر لون النص والخلفية لمعاينة التباين وقراءة نسب AA وAAA للنص العادي والكبير. يمكن تطبيق لون نص بديل عند الحاجة.
- الصق صورة أو ملف صورة بـCtrl+V (أو Cmd+V على macOS) داخل صفحة تحليل الصور، أو اسحب إليها ملف PNG أو JPEG أو WebP، ثم افحص ألوانها بحسب نسبة وجودها، واحفظ اللوحة الناتجة أو صدّرها.
- أنشئ تدرجاً خطياً أو دائرياً، وعدّل مواضع النقاط وألوانها واتجاه التدرج الخطي. احفظه في المكتبة أو انسخ CSS أو صدّره.
- اضبط حد السجل بين 1 و256 واستعد ألوانك السابقة. يبدّل «المظهر» بين الفاتح والداكن. تنقل «نسخة احتياطية» المكتبة بين أجهزة وإصدارات PickerHub.
