PickerHub is an Arabic and English desktop color workbench for Linux, Windows, and macOS. Each archive includes its runtime.

## New in 1.0.0

- Use a swatch as text or background in Contrast Check. Save the pair as semantic roles in a palette.
- Sample an image pixel with the pointer or keyboard, then copy its color, open it in the editor, or check contrast. Very large pasted bitmaps use the reduced preview and show a label.
- Includes 0.8.1’s distinct tray actions, reusable Wayland sharing, focused decisions, and compact palette layout.

## Downloads

- **Linux x64:** use `pickerhub_1.0.0_amd64.deb` on Ubuntu or Debian, or extract `PickerHub-1.0.0-linux-x64.tar.gz` on other supported distributions.
- **Windows x64:** extract `PickerHub-1.0.0-win-x64.zip` and open `PickerHub/PickerHub.exe`. Windows may show an unknown-publisher notice for this unsigned preview.
- **macOS:** extract `PickerHub-1.0.0-osx-arm64.zip` for Apple Silicon or `PickerHub-1.0.0-osx-x64.zip` for Intel. The preview bundles are ad-hoc signed and have not been notarized.
