PickerHub is an Arabic and English desktop color workbench for Linux, Windows, and macOS. Each archive includes its runtime.

## New in 0.8.1

- **Pick and copy** returns to the current tool and confirms the copied format. **Pick and edit** opens the Color Editor with HEX selected and preserves the clipboard. **Quick Pick** copies quietly with the workbench hidden.
- Start screen sharing once from the tray or Capture Mode on Wayland, then switch between pick actions with the same session. Consent and recovery actions bring the decision forward.
- Compact palettes show swatches sooner. Search preserves the swatch controls when the visible results stay the same.

## Downloads

- **Linux x64:** use `pickerhub_0.8.1_amd64.deb` on Ubuntu or Debian, or extract `PickerHub-0.8.1-linux-x64.tar.gz` on other supported distributions.
- **Windows x64:** extract `PickerHub-0.8.1-win-x64.zip` and open `PickerHub/PickerHub.exe`. Windows may show an unknown-publisher notice for this unsigned preview.
- **macOS:** extract `PickerHub-0.8.1-osx-arm64.zip` for Apple Silicon or `PickerHub-0.8.1-osx-x64.zip` for Intel. The preview bundles are ad-hoc signed and have not been notarized.
