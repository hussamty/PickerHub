# البنية

يشغّل ملف النظام التنفيذي نافذة Avalonia بواجهة عربية وتخطيط RTL، وينادي مكتبة Rust المرتبطة ديناميكياً بواجهات C. لا يعتمد التشغيل على خادم أو WebView. تنفّذ الواجهة التخزين والتنزيل عبر نظام الملفات وحوارات النظام. تحفظ المكتبة بكتابة ملف مؤقت ثم نقله فوق الملف السابق، ويحمي قفل محلي عملية التحرير من الكتابة المتزامنة عبر أكثر من مثيل. يمنع التحقق استبدال المكتبة بملف استعادة غير صالح.

## محرك Rust

يحتوي src/color.rs على تحويلات الألوان وحساب الإضاءة النسبية وعتبات التباين واقتراح البدائل. يحتوي src/names.rs على قاموس العيّنات العربية والإنجليزية. تستدعي الواجهة describe وharmony وcontrast بقيم عددية بترتيب 0xRRGGBB. تعيد هذه الدوال مؤشراً بحجم المنصة لبيانات JSON بترميز UTF-8. يقرأ المستهلك output_len وينسخ النتيجة قبل أي نداء منتج آخر على نفس الخيط. تستقبل pixel_buffer أبعاد المخزن بالبايت وترفض ما يزيد على 4 MiB. تنقل الواجهة عينة RGBA ثم تستدعي extract. يقسّم المحرك القنوات إلى 16 مستوى، ويزن المتوسطات بالشفافية. تعرض الواجهة أكبر عشر مجموعات من عيّنة يصل طول ضلعها إلى 768 بكسلاً.

## الالتقاط

| النظام | المسار |
| --- | --- |
| Windows | صورة GDI لكامل المستطيل الافتراضي في DPI الفعلي، مع غطاء Win32 أعلى الشاشات. العينة من الصورة قبل رسم الغطاء. ينتهي استحواذ المؤشر عند الاختيار أو الإلغاء. |
| Linux/X11 | اتصال Xlib مستقل، واستحواذ مؤقت للمؤشر ولوحة المفاتيح. يُقرأ البكسل من نافذة الجذر باستخدام أقنعة القنوات الفعلية. تتبع العدسة المؤشر ويضبط المستخدم تكبيرها بالعجلة. |
| Linux/Wayland | ترسل الواجهة طلب Screenshot.PickColor على ناقل جلسة المستخدم. تشترك في إشارة الاستجابة قبل الطلب، وتستخدم رمزاً مستقلاً لكل جلسة. يعيد النظام ثلاث قنوات sRGB ولا يُرسل إلى التطبيق تدفق شاشة. |
| macOS | تستدعي الواجهة NSColorSampler على خيط الواجهة وتحول NSColor إلى sRGB عبر AppKit. يعود nil عند الإلغاء. |

تتوقف الجلسة عند الاختيار أو الإلغاء. يحد النظام من الوصول إلى شاشات الأمان والمحتوى المحمي. يمكن استيراد النسخ الاحتياطية للإصدار 0.1 يدوياً من واجهة الاستعادة.

## التوزيع

يبني scripts/build.py حزمة ذاتية الاحتواء للنظام المضيف، أو يحزم مكتبات أصلية مبنية مسبقاً عند تحديد --rid و--core و--capture. يحتوي كل إصدار على مشغّل ومكتبات بالمعمارية المستهدفة. توجد المكتبات ومشغّل macOS داخل Contents/MacOS ولا يُستدعى مشغّل ملفات HTML. اختبارات Rust قابلة للتشغيل على الأنظمة الثلاثة، ويتحقق اختبار X11 من بكسل معروف خارج النافذة وإلغاء الالتقاط.
