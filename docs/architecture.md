# بنية PickerHub

يتكون التطبيق من مكتبة Rust ووحدة WebAssembly وواجهة DOM عربية. يضم سكربت البناء هذه الأجزاء والخطوط داخل ملف HTML محمول. لا يرسل التطبيق طلبات HTTP. يستخدم المتصفح حوار النظام لمشاركة الشاشة، وفك ترميز الصور، والحافظة وتنزيل الملفات.

## المحرك

- يحتوي `src/color.rs` على النوع `Color(r,g,b)`، وتحويلات sRGB وHSL وHSV وCMYK، والإضاءة النسبية والتناغم. يبحث اقتراح التباين عن أول مزيج من النص والأبيض أو الأسود يحقق 4.5:1 بعد تحويله إلى قنوات 8 بت. يختار اتجاه المزج باستخدام الخلفية.
- يحتوي `src/names.rs` على قاموس العيّنات والمسافة الموزونة بمقدار الأحمر لتسمية أقرب لون. يولّد المحرك الدرجة والتصنيف من اللون المدخل. لون العينة المرجعية مستقل عن القيمة الفعلية.
- يستقبل `dominant` بيانات RGBA. تجمع الخوارزمية كل قناة في 16 مستوى، وتحسب متوسط كل مجموعة موزوناً بالألفا، وترتب المجموعات تنازلياً بأوزانها. المقام هو مجموع أوزان كل البكسلات المرئية. يمكن أن يقل مجموع النسب المعروضة عن 100٪ عند وجود أكثر من عشر مجموعات.

## واجهة WebAssembly

تعبّأ ألوان RGB في عدد 32 بت بترتيب `0xRRGGBB`. تستدعي الواجهة دوال المحرك بشكل متزامن.

| الدالة | العقد |
| --- | --- |
| `describe(rgb)` | مؤشر JSON يحوي الصيغ والأسماء والسطوع والدرجة ولون الكتابة المقترح فوق العينة. |
| `harmony(rgb, kind)` | مؤشر مصفوفة HEX. الأنواع من 0 إلى 5 بالتسلسل الظاهر في قائمة الواجهة. |
| `contrast(fg, bg)` | مؤشر JSON لنسبة التباين الكاملة، ونتائج العتبات، وبديل لون النص. |
| `output_len()` | طول آخر نتيجة بالبايت. اقرأ UTF-8 قبل استدعاء دالة منتجة أخرى. |
| `pixel_buffer(n)` | مؤشر مخزن RGBA من n بايت، أو صفر عند تجاوز الحد أو طلب حجم صفري. |
| `extract(k)` | مؤشر JSON للنتيجة، ويحرّر مخزن RGBA. |

أعد إنشاء `Uint8Array` بعد تخصيص المخزن، فقد يتغير حجم ذاكرة WebAssembly. يستخدم المتصفح مخزن إخراج واحداً لكل مثيل. تقيس المعاينة بكسلات تدفق مصدر الشاشة بإحداثياته الفعلية، وتحوّل إحداثيات المؤشر من أبعاد العرض المصغّر. لا تقرأ الخوارزمية الشاشة كاملةً لكل حركة مؤشر.

## الواجهة والتخزين

تفصل ملفات `ui/` بين عرض المحرك وإدارة المكتبة والتقاط الشاشة وتحليل الصور والأحداث. يجمع `scripts/build.py` الملفات بترتيب اعتمادها. يُفحص توقيع ملف الصورة وأبعادها قبل فك الترميز، وتُرفض الملفات فوق 32 MiB أو 40 مليون بكسل. يبقى أصل الصورة والتدفق في الذاكرة. تمثل صيغة JSON ذات `version: 1` المكتبة المحلية، مع معرّف مستقل لكل لوحة ولون محفوظ وتدرج. يتناول التحقق من الاستعادة حدود الأعداد وصيغ الألوان والأسماء والمواقع قبل استبدال المكتبة.

تعيد عمليات التعديل قراءة الحالة الحالية ثم تكتب المكتبة كاملة في عملية تخزين واحدة. تنسّق Web Locks بين التبويبات عند توفرها ويتابع المستمع لتغيرات التخزين تحديث العرض. في المتصفحات التي لا تقدم Web Locks، استخدم تبويباً واحداً لتحرير المكتبة. فشل الكتابة يبقي آخر مكتبة محفوظة متاحة. احتفظ بنسخة JSON لنقل المكتبة بين الأجهزة أو لنقل مسار التثبيت.

## التحقق قبل الإصدار

شغّل اختبارات Rust، ثم ابنِ الملف وشغّل اختبار المتصفح كما في CONTRIBUTING.md. على كل نظام مستهدف افتح الحزمة من مدير الملفات، واختر لون نافذة معروفة، ثم شاشة ثانية عند توفرها. قارن قيم القطّارة والمعاينة مع عينة sRGB معروفة، وجرّب إلغاء الإذن وإغلاق المعاينة وتحقق من إيقاف المشاركة. تستخدم الاختبارات الآلية تدفقاً تجريبياً وتبقى نافذة الأذونات والنظام وشاشات HiDPI جزءاً من اختبار الجهاز الفعلي.
