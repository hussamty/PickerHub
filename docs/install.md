# تثبيت PickerHub لسطح المكتب

اختر حزمة الإصدار لنظامك ومعمارية جهازك من الملفات المرفقة أو قسم Releases بعد نشر المستودع. يتضمن كل توزيع محرك Rust وواجهة التطبيق وبيئة تشغيل .NET. فك ضغط الحزمة كاملةً قبل التشغيل واحتفظ بالملفات المجاورة للمشغّل. توجد بصمة SHA-256 بجانب كل حزمة.

## Windows

نزّل **PickerHub-0.2.0-win-x64.zip** لجهاز Windows 10/11 بنظام x64. من مستكشف الملفات اختر **Extract All**، ثم افتح **PickerHub.exe** داخل المجلد. يمكنك إنشاء اختصار لملف التشغيل. يستخدم التطبيق قطّارة Win32 على كامل سطح المكتب الافتراضي. يشمل ذلك الشاشات الممتدة والموضوعة إلى يسار الشاشة الرئيسية. عند النقر على «القطّارة» تتجمد صورة سطح المكتب للاختيار. انقر لتثبيت اللون، أو اضغط Esc للإلغاء. استخدم العجلة لتغيير التكبير والأسهم للتنقل.

ملفات التسليم المحلي غير موقّعة بشهادة ناشر Windows. تحقق من بصمة الحزمة باستخدام `Get-FileHash .\PickerHub-0.2.0-win-x64.zip`. إذا منع الجهاز تشغيل التطبيقات غير الموقعة، يمكن بناء نسخة من المصدر ضمن سياسة المؤسسة. احتفظ بمجلد التطبيق كاملاً إذا ظهرت رسالة عن DLL مفقود.

## Linux

**Ubuntu وDebian على x86-64:** نزّل **pickerhub_0.2.0_amd64.deb**. نفّذ الأمر من مجلد التنزيل ثم افتح PickerHub من قائمة التطبيقات أو شغّل `pickerhub`.

```sh
sudo apt install ./pickerhub_0.2.0_amd64.deb
```

تحل هذه الحزمة محل مشغّل الإصدار 0.1 المُثبت عبر apt. لتثبيت محلي بلا صلاحيات مسؤول على Ubuntu أو Fedora أو Arch أو openSUSE، فك **PickerHub-0.2.0-linux-x64.tar.gz** في مجلد ثابت، ثم شغّل `./PickerHub/PickerHub`. يحتاج التطبيق إلى سطح مكتب رسومي وX11 أو XWayland، ومكتبات fontconfig وICU وOpenSSL المعتادة. متطلبات glibc لمحرك Rust تتبع النظام الذي بُنيت عليه الحزمة. إذا ظهرت رسالة GLIBC أحدث، ابنِ على توزيعتك أو استخدم حزمة من نظام بناء متوافق.

- **GNOME وKDE على Wayland:** يستدعي التطبيق خدمة PickColor التابعة للبوابة النظامية مباشرةً. عند ظهور إذن النظام اسمح بالاختيار ثم انقر على البكسل. لا يحتاج المستخدم إلى اختيار شاشة مشاركة. إذا لم تظهر القطّارة، تحقق من تشغيل xdg-desktop-portal ومن توافر خلفية تدعم PickColor لبيئة سطح المكتب. يفيد الأمر `systemctl --user status xdg-desktop-portal`. [واجهة PickColor](https://flatpak.github.io/xdg-desktop-portal/docs/doc-org.freedesktop.portal.Screenshot.html)
- **X11:** تفتح القطّارة مؤشراً وعدسة مباشرة. انقر على بكسل في سطح المكتب الممتد. Esc أو الزر الأيمن يلغي العملية. إذا كان برنامج آخر يستحوذ على المؤشر، أغلق أداة الالتقاط الأخرى وأعد المحاولة.
- إذا كنت تستخدم نسختين من التطبيق، تكون المكتبة قابلة للتحرير في النسخة الأولى. أغلق النسخة الأخرى وأعد تشغيل التطبيق لاستعادة التحرير.

## macOS

استخدم **PickerHub-0.2.0-osx-arm64.zip** لأجهزة Apple Silicon أو **PickerHub-0.2.0-osx-x64.zip** لأجهزة Intel. يستهدف التطبيق macOS 14 أو أحدث ضمن فترة دعم بيئة التشغيل. فك الضغط ثم انقل **PickerHub.app** إلى Applications وافتحه من Finder. تشغّل «القطّارة» عدسة الألوان النظامية NSColorSampler. يتولى AppKit اختيار بكسل من الشاشات المتصلة ويعيده بصيغة sRGB. [توثيق Apple](https://developer.apple.com/documentation/appkit/nscolorsampler)

الحزم المحلية غير موثقة لدى Apple. إذا حجب Gatekeeper تشغيل التطبيق يمكنك بناء نسخة محلية بالطريقة أدناه. قارن البصمة باستخدام `shasum -a 256`. على جهاز تديره مؤسسة راجع سياسة تثبيت تطبيقات سطح المكتب.

## البناء من المصدر

ثبّت Rust المستقر و.NET SDK 10 وPython 3.9 أو أحدث. يتطلب البناء الأول اتصالاً لتنزيل تبعيات Cargo وNuGet. لا يحتاج مستخدم الحزمة الجاهزة إلى أدوات البناء. استخدم مجلد المشروع الذي يحتوي على Cargo.toml.

| النظام | أدوات إضافية |
| --- | --- |
| Windows x64 | Visual Studio Build Tools مع C++ وWindows SDK. افتح x64 Native Tools Command Prompt واستخدم `py -3` مكان `python3`. |
| Linux x64 | مترجم C ورؤوس Xlib. على Ubuntu/Debian ثبّت `build-essential libx11-dev`. يضيف dpkg-deb حزمة Debian عند توفره. |
| macOS | ثبّت أدوات Apple عبر `xcode-select --install`. يختار السكربت معمارية جهاز البناء، ويوقّع الحزمة محلياً عند البناء على Mac. |

```sh
cargo test --locked
python3 scripts/build.py --packages
```

ينتج السكربت مجلد تطبيق قابل للتشغيل في `dist/native/<rid>/` بالإضافة إلى الأرشيف. استخدم **نسخة احتياطية** قبل الانتقال إلى جهاز أو تثبيت جديد. تحتفظ المكتبة بالاسم `workspace.json` في مجلد بيانات PickerHub المحلي. على Linux يتبع المسار XDG_DATA_HOME أو ‎~/.local/share‎، وعلى Windows يتبع LocalAppData، وعلى macOS يتبع Application Support.
